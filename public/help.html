16-step pocket sequencer — cheatsheet

Patterns (top row)

1–8 Switch pattern. While playing, queues the switch at end of loop.
active Filled = current pattern. Dashed outline = queued (pending).

Step grid (16 buttons)

tap Toggle step on/off for the active track.
hold Open pitch & volume editor for that step (melodic tracks only show pitch keyboard; drum tracks go straight to volume).
cross-hatch White theme only: hatch density = velocity. Denser = quieter.
number label Semitone offset from root (e.g. +7, -2).

Tracks

KK SN HH OH
CP RM TM SY		 Built-in drum/synth tracks. Tap to select.
S1–S8 Custom sample slots. Tap to select. Hold to open sample menu.
dashed border Custom slot has no sample loaded yet.
SY track Melodic — pitch changes playback rate (PO-style, changes duration too).

Sample menu (hold custom track)

Record mic Capture from microphone. Browser will request permission.
Load file Import any audio file from device.
Trim Open waveform trim editor. Drag handles to set start/end. Saved non-destructively.
Clear Remove the loaded sample from this slot.

Actions bar

CLEAR Wipe all steps across all 8 patterns (confirmation required).
COPY Copy a pattern or sample.
With a drum/synth track active: tap COPY → tap source pattern → tap destination pattern.
With a custom track active: tap COPY → tap source custom track → tap destination custom track.
Tap COPY again at any time to cancel.

Transport

− + Decrease / increase BPM by 1. Hold for fast repeat.
PLAY / STOP Start or stop playback. Pattern switches queue on PLAY.
PATCH Open patch menu: Export WAV · Save file · Load file.

Patch menu

Export WAV Render one full loop of the current pattern to a WAV file and download it.
Save file Download a .bbp project file (all patterns + samples).
Load file Import a .bbp project file, replacing current state.

State is saved to localStorage automatically after every change.
Audio context resumes on first interaction (required by browsers).
